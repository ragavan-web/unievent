UniEvent Guide: How It Works

For Students

  1. Sign Up / Login using your official email or register number.
  2. Explore Events on the dashboard, filtering by department or type.
  3. View Details to see all nested competitions.
  4. Register for competitions (our system automatically checks and enforces limits set by the organizer).
  5. Track all your sign-ups on the "My Registrations" page.

For Organizers

  1. Register your departmental account using your official staff email.
  2. Post New Event using the form, including event dates, venue, and a simulated photo URL.
  3. Define Competitions, setting unique rules (team size, fee, coordinator contact) for each one.
  4. The system automatically runs a **Venue Conflict Check** before submission.
  5. Manage Registrations by viewing the live report table for student lists and details.
