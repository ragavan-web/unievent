UniEvent - https://unievent-92ku.onrender.com/

UniEvent is a web-based application designed to simplify event management in universities and colleges. It provides a centralized platform for organizing, managing, and participating in academic, cultural, and technical events efficiently.

Features

User-friendly interface for students and organizers

Event creation and management by administrators

View upcoming, ongoing, and past events

Event registration for students

Event details including date, time, venue, and description

Responsive design for desktop and mobile devices

 Technologies Used

Frontend: HTML, CSS, JavaScript

Backend:  Node.js 

Database: SQLite

Tools: Git, GitHub


Future Enhancements

Login & authentication system

Email or notification alerts

Event attendance tracking

Role-based access (Admin / Organizer / Student)
